**Project Coco** is a cozy, procedurally generated isometric city simulation built for the browser. It is a **shared, pure-observer AI diorama** where every visitor to the site watches the *same* living city at the exact same moment. Ten unique monster agents live autonomous lives driven by a needs-utility AI, building relationships that evolve from strangers to close friends in real time.

---

## 🌟 Key Features

*   **🌐 Globally Synchronized Simulation:** The game uses deterministic integer math anchored to the real-world clock. Every player on Earth sees the exact same characters, in the exact same positions, doing the same activities at any given second.
*   **🧠 Needs-Utility Agent Brain:** Ten distinct monster agents go about their daily routines (sleeping, working, grabbing a snack at the café, relaxing in the park, and socializing). They choose activities based on five decaying needs (Energy, Hunger, Social, Fun, Purpose) and their specific personality archetype (e.g., *The Connector*, *The Hustler*, *The Night Owl*).
*   **📈 Emergent Social Graph:** When agents are near each other at local hotspots, they chat. These interactions raise their sentiment score, eventually upgrading their relationship status (e.g., becoming friends or close friends) which broadcasts to a live global story feed.
*   **🎨 Modular & Procedural Rendering:**
    *   **Buildings:** Stacks are generated dynamically (base + storeys + roof) depending on their building type and tier.
    *   **Monsters:** Walker sprites are procedurally assembled from body parts, limbs, eyes, mouths, and accessories using the Kenney Monster Builder Pack.
    *   **Animations:** Dynamic procedural leg/arm swings adapt to walking or running speeds, combined with breathing bobs for idle states.
*   **🌗 Real-Time Day/Night Cycle:** The world changes lighting (Dawn, Day, Dusk, Night) in lockstep with the viewer's local clock.
*   **📱 Mobile-First Controls:** Optimized for portrait layout on mobile browsers with smooth touch-drag panning, pinch-to-zoom, and double-tap interactions.

## 🚀 Installation & Setup

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) and `npm` installed.

### 1. Clone the Repository
```bash
git clone git@github.com:kanudeeptech/Project-COCO---AI-Monster-City.git
cd Project-COCO---AI-Monster-City
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
Start the local server with hot-reloading:
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173` (or the port specified in your terminal).

### 4. Build for Production
To bundle the game for deployment:
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

### 5. Run Tests
To execute the Vitest test suite (validating the economy, agent social loops, and deterministic generator behavior):
```bash
npm run test
```

## 📂 Project Architecture

```
src/
  ├── citygen/       # Procedural generator pipeline (grid, road-tiling, placements)
  ├── core/          # Deterministic PRNG and global system clock
  ├── data/          # Color palettes and building structures
  ├── scenes/        # Phaser scenes (Boot, Game, UI, and Tile Gallery)
  ├── sim/           # Simulation brains (Agents, Needs, Traffic, Walkers)
  ├── state/         # Dual-write save manager (localStorage + IndexedDB)
  └── world/         # Isometric math and A* pathfinding
```

## 🎮 How to Interact

Since Project Coco is a **pure-observer diorama**, there are no building actions or dark patterns. Instead, you can:
*   **Pan & Zoom:** Click and drag (or swipe) to look around. Scroll or pinch to zoom in/out.
*   **Tap a Monster:** Tapping any walking monster opens their **Agent Card** showing their archetype, active task, relationship graph, and current needs status.
*   **Follow Mode:** Click the **👁 Follow** button on an agent card to lock the camera on that monster and watch their daily commute.
*   **Seed Browser:** Use the arrow buttons `◀` and `▶` or the `🎲` dice button in the UI to explore candidate cities generated by different seeds.
